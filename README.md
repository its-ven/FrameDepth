# FrameDepth
Enjoy your media on your Steam Frame / SteamVR with true 3D depth.
TLDR: Python 3.13, Install requirements, run SteamVR, run depth3d_br.bat, press A on your controller to bring up options.

Vibecoded and tested in an evening. Any games, videos, photos, whatever, will have depth applied thanks to Depth2Anything. Tested on a 1440p monitor on an Nvidia 5070Ti.
May need a little tweaking for your own use case and hardware. Tested for a few days with non-VR games, Netflix and YouTube, and it works great.

NOTE: I won't be maintaining this project or PRs. Use this as a boilerplate, fork it and go wild.
